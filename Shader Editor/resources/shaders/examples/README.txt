Примеры шейдеров для Shader Editor
==================================

Как использовать: скопируйте содержимое .vert-файла во вкладку "Vertex shader",
а содержимое .frag - во вкладку "Fragment shader". Для каждого примера нужны
ОБА файла с одинаковым номером (вершинный и фрагментный шейдер).

Результат виден сразу: редактор перекомпилирует шейдеры при каждом изменении.

Что доступно из программы
-------------------------

Атрибуты вершин (in):
  position  vec3  - позиция вершины в координатах модели
  normal    vec3  - нормаль вершины

Uniform-переменные (uniform):
  model          mat4   - матрица трансформации модели (поворот/сдвиг мышью)
  view           mat4   - матрица камеры
  projection     mat4   - матрица проекции
  normalMatrix   mat3   - матрица для трансформации нормалей
  time           float  - секунды с момента запуска (для анимации)
  cameraPosition vec3   - позиция камеры

Список примеров
---------------

01_normals   - раскраска по нормалям: базовый инструмент отладки геометрии
02_plasma    - анимированная радужная плазма на поверхности модели
03_wave      - волны: геометрия деформируется в вершинном шейдере
04_toon      - cel shading: мультяшные ступени освещения и контур
05_fresnel   - неоновая кайма по силуэту модели (эффект Френеля)
